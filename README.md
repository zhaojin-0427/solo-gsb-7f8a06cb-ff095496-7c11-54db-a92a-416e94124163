# 骑马订 PDF 拼版（本地网页工具）

用 **Node.js + Express + pdf-lib + PDF.js + 原生前端** 实现的本地骑马订（saddle stitch）PDF 工具，包含六部分：

1. **骑马订拼版**：首页上传 PDF，按帖拼版并下载；
2. **印前文字安全区预检**：上传原稿并填写裁切/装订边距，逐页检查文字是否穿入边缘禁入带；
3. **原稿页脚页码核对**：上传原稿并指定首个带页码页、起始页码与页脚带高度，逐页核对页脚页码是否连续正确；
4. **原稿字体嵌入核查**：上传原稿，逐页检查资源字典中引用的字体是否嵌入字体文件；
5. **原稿位图有效分辨率预检**：上传原稿并填写最低分辨率（72～1200 DPI），追踪 PDF.js 绘制指令与图形状态，逐次计算实际绘制位图的横、纵有效 DPI；
6. **裁切与出血盒核验**：上传原稿并填写成品宽、高与最低出血量，逐页核对 TrimBox 成品尺寸并逐边计算可用出血。

所有处理均在你自己的电脑（或本机 Docker 容器）内完成，文件不上传到任何外部服务器。

## 功能

- 上传一个 **各页同尺寸、无旋转、未加密** 的 PDF。
- 每帖可选 **4 / 8 / 16 页**；按原顺序分帖，**末帖尾部补白**至所选页数。
- 对每帖的第 i 张纸（i 从 0 起，N 为该帖总页数）：
  - **正面**：左 = 第 `N − 2i` 页，右 = 第 `1 + 2i` 页
  - **背面**：左 = 第 `2 + 2i` 页，右 = 第 `N − 1 − 2i` 页
- 输出 PDF 按每张纸 **正面、背面交替** 排列；每面宽为原页两倍，**原页不缩放**（100%）。
- 页面以表格逐帖列出每个输出面对应的**原页号**与**空白位（补白）**，核对无误后再下载拼版文件。
- 以下情况会在页面上给出明确中文错误：
  - 文件损坏 / 不是有效 PDF
  - PDF 已加密（含打开密码或权限加密）
  - 各页尺寸不一致
  - 含有旋转页面（旋转角不为 0）

## 印前文字安全区预检（预检入口）

启动后访问 **http://localhost:3000/preflight.html**（首页顶部有「印前文字安全区预检 →」链接，预检页可返回拼版页）。

使用步骤：

1. 选择原稿 PDF（沿用拼版页相同的上传限制：PDF 文件、上限 100 MB、未加密；预检按页处理，允许页面旋转、页尺寸不一致）。
2. 填写 **裁切边距** 与 **装订边距**（毫米）：均须大于 0，且小于页面短边的一半。
3. 点击「上传并预检」，报告按页列出：文字片段、风险边（实际边距 / 要求边距）与最小边距。

判定规则：

- 以每页**可见页框**（CropBox，含页面旋转后的视口）为界；
- **奇数页左侧、偶数页右侧**为装订边（使用装订边距），其余三边（上、下及另一侧）使用裁切边距；
- 页内**旋转文字**取变换后的轴对齐外接框；
- 文本框**穿入**边缘禁入带（距离严格小于边距）才报风险，**恰好贴边不报**；同一文本触及多边时**逐边列出**；
- 实际距离以毫米给出，**越出页框记为负值**；
- 无可提取文字的页标记为「无法判断」——**图像（扫描件）中的文字未纳入检查**。

## 原稿页脚页码核对（页码核对入口）

启动后访问 **http://localhost:3000/pagenumbers.html**（首页与预检页顶部均有「原稿页脚页码核对 →」链接，页码核对页可返回拼版页或前往预检页）。

使用步骤：

1. 选择原稿 PDF（沿用拼版页相同的上传限制：PDF 文件、上限 100 MB、未加密；核对按页处理，允许页面旋转、页尺寸不一致）。
2. 填写三项设置：
   - **首个带页码的 PDF 页序**：1 至总页数；此前的页跳过不核对；
   - **该页印刷页码**：正整数；自该页起期望页码按 PDF 页序逐页 +1；
   - **页脚带高度**（毫米）：大于 0 且小于最矮页高度的一半。
3. 点击「上传并核对」，报告逐页列出：PDF 页序、提取页码、期望页码与异常说明，并汇总错号数与无法判断数。

识别范围与判定规则：

- 只识别**完整落在可见页框（CropBox，含页面旋转后的视口）底部带内**的**横排**（书写方向水平朝右）**纯阿拉伯数字**文本（半角 `0-9`、全角 `０-９`）；带外文字、竖排/旋转文字、夹杂其他字符的片段（如「第 12 页」）均不参与；
- **同基线**（纵向容差 1 pt 内）且**水平间隔不超过 2 mm** 的数字片段按**几何位置**（x 升序）拼接为一个候选，不按提取顺序盲连；间隔更大或不同基线的数字各自成为独立候选；
- 每页**恰有一个候选**才与期望页码核对：**无候选**或**多个候选**时标记为「无法判断」；
- 期望页码只随 PDF 页序递增，**不随提取结果调整**（某页无法判断不影响后续页的期望值）；
- 图像（扫描件）中的页码未纳入识别。

## 原稿字体嵌入核查（字体核查入口）

启动后访问 **http://localhost:3000/fonts.html**（首页、预检页与页码核对页顶部均有「原稿字体嵌入核查 →」链接，字体核查页可返回拼版页或前往其他核对页）。

使用步骤：

1. 选择原稿 PDF（沿用拼版页相同的上传限制：单个 PDF 文件、上限 100 MB、未加密；核查按页处理，允许页面旋转、页尺寸不一致）。
2. 点击「上传并核查」，报告逐页列出每条字体引用的**资源名、BaseFont、来源（页面资源 / 表单 XObject 层级）与状态**，并汇总有未嵌入字体的页数及各状态数量。

检查范围与判定规则：

- 逐页读取页面 **Resources/Font** 字体字典（**含自 Pages 父节点继承的 Resources**），并**递归进入页面资源中引用的 Form XObject**，检查其自带 Resources 里的字体；**同一表单被多页引用时逐页计入**，表单循环引用按页去重、不会卡住核查；
- **普通字体**（Type1 / MMType1 / TrueType / CIDFontType0 / CIDFontType2）检查 FontDescriptor 中的 **FontFile、FontFile2、FontFile3**；**Type0 字体沿 DescendantFonts 子字体**查找（全部子字体均嵌入才算已嵌入）；对应字段为**非空 PDF 流**才算已嵌入，**缺少描述符或字体流算未嵌入**（空流同样算未嵌入）；
- **Type3 字体**标为「内置字形」——字形由 PDF 内容流内建定义，无需嵌入字体文件；
- **未嵌入的标准 14 字体**（Helvetica / Times / Courier / Symbol / ZapfDingbats 族，忽略子集前缀）单列为「**可替代**」，不计入未嵌入；
- **损坏的字体字典**（条目不是字典、子类型无法识别、Type0 缺少子字体等）标为「**无法判断**」；
- 检查对象是**资源字典中的字体引用**，**不判断字形是否在页面中实际绘制**；未被资源引用的字体、以及图像（扫描件）中的文字不纳入检查。

## 原稿位图有效分辨率预检（位图分辨率入口）

启动后访问 **http://localhost:3000/imageresolution.html**（首页、预检页、页码核对页与字体核查页顶部均有「原稿位图有效分辨率预检 →」链接，该页可返回拼版页或前往其他核对页）。

使用步骤：

1. 选择原稿 PDF（沿用拼版页相同的上传限制：单个 PDF 文件、上限 100 MB、未加密；预检按页处理，允许页面旋转、页尺寸不一致）。
2. 填写 **最低分辨率（DPI）**：72～1200 之间的整数（默认 300）。
3. 点击「上传并预检」，报告逐页列出每一处位图放置的**图片尺寸（像素）、放置尺寸（mm）、横向 DPI、纵向 DPI 与有效 DPI**，并汇总风险放置数；无位图绘制的页标记为「**无图**」。

检查范围与判定规则：

- 程序读取 **PDF.js 绘制指令**（operatorList），随 **save / restore（q/Q）与 transform（cm）** 追踪图形状态（CTM）；绘制 **Form XObject** 时把表单自带的 **Matrix** 纳入追踪，因此**嵌套表单内的位图**按页面上的最终变换计算；
- **只核查内容流中实际绘制的普通 Image XObject**——仅在资源字典（Resources/XObject）中出现、从未被 `Do` 绘制的图片**不计入**；**同一图像多次放置时逐次计算**（每处放置单独列一行）；
- 每次放置以**图像像素宽、高**分别除以变换后的**横、纵边长（英寸，72 pt = 1 英寸）**得到横向、纵向两个 DPI，取**较小值**与阈值比较：**严格低于**阈值才报风险（**恰好等于阈值不报**）；
- **旋转**（如 90°、45°）放置按变换后图像横边、纵边向量的实际模长计算；**非等比缩放**时横、纵 DPI 分别计算，较低方向决定判定结果；
- **内联图像（BI…EI）、图像蒙版（ImageMask）不纳入检查**；**不判断图像是否被裁切（clip）或遮挡**（被遮罩/其他对象盖住的图片只要有绘制指令仍按放置尺寸计入）。

## 裁切与出血盒核验（裁切/出血盒入口）

启动后访问 **http://localhost:3000/bleedboxes.html**（首页及各核对页顶部均有「裁切与出血盒核验 →」链接，该页可返回拼版页或前往其他核对页）。

使用步骤：

1. 选择原稿 PDF（沿用拼版页相同的上传限制：单个 PDF 文件、上限 100 MB、未加密；核验按页处理，允许页面旋转、页尺寸不一致）。
2. 填写 **成品宽度、成品高度与最低出血量**（毫米）：三项均须大于 0。
3. 点击「上传并核验」，报告逐页列出：MediaBox / CropBox / TrimBox / BleedBox 的原点与宽高、TrimBox 与成品尺寸的核对结果、四边可用出血毫米值与页面状态，并汇总风险页、未声明页与无法判断页。

读取范围与判定规则：

- 逐页读取**继承的 MediaBox、CropBox、Rotate**：CropBox 缺省时取 MediaBox，Rotate 缺省时取 0 度（只接受 0/90/180/270 度，其他角度视为无效）；
- **TrimBox、BleedBox 只读取页面显式声明的条目**，缺少时标为「**未声明**」，**不套用默认盒**（不回退到 CropBox）；声明了但不是 4 个数字构成的有效正数矩形时标为「**无法判断**」；
- 按 **Rotate 旋转后的阅读方向**（宽对宽、高对高）比较 TrimBox 与成品尺寸：宽、高任一相差**严格超过 0.5 mm** 报「**尺寸不符**」，0.5 mm 及以内视为相符；
- 把 **BleedBox 与 CropBox、MediaBox 的交集**作为「**可用出血范围**」（交集为空或退化时无法判断），逐边（左/右/上/下，阅读方向）计算它超出 TrimBox 的距离：**严格小于**最低出血量才报风险，**恰好达到不报**；距离为负表示可用出血范围未覆盖 TrimBox 该边；
- **非零盒原点**（llx/lly 不为 0）按盒坐标原样参与运算；**90/180/270 度旋转**先在默认用户空间取盒、再逐点映射到阅读方向，四边归属随之旋转；
- 本核验**只检查盒几何（位置与尺寸），不判断页面画面（图像、底色等）是否实际铺满出血区**。

## 一条命令启动（Docker Compose）

```bash
docker compose up --build
```

启动后浏览器打开：

> **http://localhost:3000**

- 容器内监听端口：**3000**
- 宿主机映射端口：**3000**（在 `docker-compose.yml` 的 `ports` 中修改，例如 `"8080:3000"` 后访问 http://localhost:8080）

后台运行：`docker compose up --build -d`；停止：`docker compose down`。

## 使用步骤（拼版）

1. 打开 http://localhost:3000
2. 选择 PDF 文件，选择每帖页数（4 / 8 / 16，默认 8），点击「上传并拼版」。
3. 查看拼版摘要与逐帖核对表：
   - 蓝色标签「第 x 页」为原页；灰色「空白（帖内第 n 位）」为补白位。
   - 表格按输出 PDF 的面顺序排列：第 1 张正面、第 1 张背面、第 2 张正面……
4. 点击「下载拼版 PDF」。

## 打印设置（重要）

拼版文件每个输出面宽为原页的 2 倍（两张原页并排），打印时请设置：

- **双面打印**
- **横向（Landscape）**
- **短边翻转 / 短边装订翻转（Flip on short edge）**
- 缩放 **100%（实际大小，不要"适合页面"）**
- 纸张尺寸：输出面尺寸 = 原页宽 × 2（例：A4 原页 → 输出面为 A3 横向），
  请选择能并排放下两页的纸张，或在支持海报/缩放的打印机上自行处理。

打印后将整叠纸沿中缝对折成套，即为骑马订书帖；多帖时按帖序套叠。

## 说明与限制

- 拼版结果仅保存在服务内存中，约 1 小时后自动删除；服务重启即清空，不向磁盘写文件。
- 拼版仅处理各页同尺寸、旋转角为 0 的 PDF；不支持异形页、旋转页或加密 PDF（会明确报错）。
- 原页按其裁切框/媒体框内容原样放置，不做缩放、裁切或旋转。
- 预检在服务端用 PDF.js 逐页提取文字；仅可提取的文本会被检查，图像/扫描件文字不纳入（该类页面标为「无法判断」）。
- 预检报告中的文本框采用 PDF.js 文本项几何（基线起点 + 文本宽度/字高的变换外接框，与页面文字选区范围一致），并非逐字形墨迹外轮廓。
- 页码核对同样在服务端用 PDF.js 提取文字；仅页脚带内完整落入的横排纯数字片段参与识别，图像/扫描件页码、竖排页码、带装饰字符的页码（如「- 12 -」）均不识别（相应页标为「无法判断」）。
- 字体嵌入核查在服务端用 pdf-lib 直接读取 PDF 对象结构：只检查页面（含继承）与表单 XObject 资源字典中引用的字体，不渲染页面、不判断字形是否实际绘制；字体子集是否包含全部所用字形、字体许可是否允许嵌入等均不在检查范围内。
- 位图有效分辨率预检在服务端用 PDF.js 读取绘制指令：只统计内容流（含表单 XObject）中**实际绘制**的普通 Image XObject，不把资源字典中的未用图片计入；**内联图像、图像蒙版不纳入**；边长由绘制时的当前变换矩阵（CTM，含表单 Matrix 嵌套）计算，旋转与非等比缩放在横、纵方向分别求 DPI；**不判断图像是否被裁切或遮挡**。
- 裁切与出血盒核验在服务端用 pdf-lib 读取页面盒：MediaBox / CropBox / Rotate 取继承值（CropBox、Rotate 缺省分别取 MediaBox、0 度），TrimBox / BleedBox **只认页面显式声明、不套用默认盒**；按旋转后阅读方向核对成品尺寸（容差 0.5 mm），可用出血为 BleedBox ∩ CropBox ∩ MediaBox 并逐边比较最低出血量；**只核验盒几何，不判断画面是否铺满出血区**，也不检查盒外内容是否会被错误裁切。
